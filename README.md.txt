# Melbourne Metro Rail Patronage Analytics (2018–2025)

## Project Overview

Melbourne's metropolitan rail network is a critical component of the city's transport infrastructure, supporting millions of passenger journeys each year. Understanding how passenger demand changes over time is essential for effective transport planning, operational decision-making, and future infrastructure investment.

This project analyses Melbourne metropolitan train station patronage data from 2018 to 2025 to identify passenger demand trends, station utilisation patterns, and post-COVID recovery across the rail network. Using Python, SQL, and Power BI, the project transforms raw operational data into meaningful insights that support data-driven decision-making.

## Business Objective

The objective of this project is to analyse historical train station patronage data and uncover trends in passenger demand across Melbourne's metropolitan rail network. The analysis aims to identify high-performing stations, growth patterns, and the impact of COVID-19 on network usage, while providing insights that could support transport planning and operational improvements.

## Dataset

- **Source:** Victorian Government Open Data Portal
- **Coverage:** 2018–2019 to 2024–2025
- **Domain:** Public Transport / Rail Operations
- **Data:** Annual metropolitan train station patronage and utilisation metrics

## Tools & Technologies

- **Python** (Pandas, NumPy, Matplotlib)
- **SQL** (SQLite)
- **Power BI**
- **Git & GitHub**

## Key Business Questions

- Which stations have the highest passenger demand?
- How has patronage changed between 2018 and 2025?
- What impact did COVID-19 have on rail usage?
- Which stations recovered fastest following the pandemic?
- Which stations are experiencing the strongest long-term growth?
- What operational insights can be derived from network utilisation patterns?

## Methodology

1. Collect and consolidate annual patronage datasets.
2. Clean and prepare the data for analysis.
3. Perform exploratory data analysis (EDA) to identify trends and patterns.
4. Develop SQL queries to answer key business questions.
5. Build an interactive Power BI dashboard to visualise findings.
6. Generate business insights and recommendations.
